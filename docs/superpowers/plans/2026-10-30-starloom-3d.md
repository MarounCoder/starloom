# Starloom 3D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild Starloom as an infinite 3D universe: the real Solar System and real stars near home, real and user-made constellations that you play like an instrument, and a generated universe of galaxies beyond, explored by free flight.

**Architecture:** Pure, tested modules in `src/lib/space` own all the physics, data decoding, generation, flight maths and music mapping in float64 kilometres. `src/scene` is a thin React Three Fiber layer: every frame it subtracts the camera position from every object's float64 position (floating origin, camera always at 0,0,0) and hands float32 offsets to three.js. Mutable modules in `src/state` hold the camera and clock (no React re-renders per frame); Zustand holds the user's sky and the HUD state.

**Tech Stack:** React 19, TypeScript 6, Vite 8, three 0.187, @react-three/fiber 9, @react-three/drei 10, @react-three/postprocessing 3, astronomy-engine 2.1, Zustand 5, lz-string, lucide-react 1, Fontsource, Vitest 5, Playwright-core (local screenshots only), GitHub Actions + Pages.

**Spec:** `docs/superpowers/specs/2026-10-30-starloom-3d-design.md`

### Task 5: Free flight

**Files:**
- Create: `src/lib/space/flight.ts`, `flight.test.ts`, `src/state/flight.ts`, `src/scene/FlightInput.tsx`
- Modify: `src/state/camera.ts`, `src/scene/Universe.tsx`

**Interfaces:**
- Consumes: `cam` (Task 3), `positions()`, `BODIES`, catalogue (Task 4).
- Produces:
  - `flight.ts` (pure):
    - `interface Flight { vel: V3; yawVel: number; pitchVel: number; orbit: { target: string; dist: number; yaw: number; pitch: number } | null; travel: Travel | null }`
    - `speedFor(nearestKm: number): number` = `clamp(nearestKm * 0.9, 0.2, 1e30)` km/s (you cover the distance to the nearest thing in about a second).
    - `nearestSurface(pos: V3, bodies: { pos: V3; radius: number }[], starsKm: V3[] | null): number` (min of `dist − radius`; stars count with radius 0 and are passed in pre-filtered to the 64 nearest).
    - `stepFree(f, cam, input: { thrust: V3 /* camera-space −1..1 */; wheel: number; wheelDir: V3; look: [dx, dy] }, nearestKm, dt, reduced): void` — wheel and keys add velocity along the pointer ray / camera axes scaled by `speedFor`; glide damping `vel *= exp(−dt / 0.35)` (none when reduced: velocity zeroed after each step); look velocity damps with τ = 0.25 s.
    - `clampOutside(pos: V3, bodies, margin = 1.08): V3` — if inside `radius × margin` of a body, project onto that shell.
    - `stepOrbit(f, cam, targetPos: V3, targetRadius, input, dt)` — drag changes orbit yaw/pitch, wheel scales `dist` by `exp(−wheel × 0.0015)` clamped to `[radius × 1.15, ∞)`; camera looks at the target.
    - `travelPath(from: V3, to: V3, arriveDist: number, t: number): V3` — distance to `to` shrinks geometrically, `d(t) = d0^(1−e) · arriveDist^e` with `e = easeInOutCubic(t)`, along the straight line; `travelDuration(d0, arriveDist) = clamp(1.2 + 0.25·log10(d0 / arriveDist), 1.2, 4)` seconds.
  - `state/flight.ts`: `flyTo(target: Target)` where `type Target = { kind: 'body'; id: BodyId } | { kind: 'star'; id: StarId } | { kind: 'point'; pos: V3; arriveKm: number }` (arrival distance: body radius × 4, star 0.02 pc × max(1, luminosity^0.5), point as given; bodies enter orbit on arrival); `cancelTravel()` on any user input; `exitOrbit()`; reduced motion jumps straight to the end.
  - `FlightInput.tsx`: pointer drag (look, or orbit when orbiting), wheel, pinch (= wheel), WASD/arrows (thrust; Q/E down/up), Shift = ×4; taps go to `onTap(x, y)` using `isTap` (Task 6 wires it). Esc exits orbit.

  - From Earth's surface shell, 5 s of full wheel thrust toward Earth never ends inside `radius × 1.08` (`clampOutside` each step).
  - Starting 1e8 ly from the Sun with velocity pointing home, 600 steps of 1/60 s keep every component of `cam.pos` and `vel` finite.

  - Reduced motion: after one `stepFree`, `vel` is `[0, 0, 0]`.
