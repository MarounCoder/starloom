# Starloom Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Starloom, an infinite, playable night sky, as a React app deployed to GitHub Pages.

**Architecture:** Pure, tested modules in `src/lib` (world generation, music, sharing, astronomy, constellation ops) feed a single imperative canvas renderer in `src/render`. React components in `src/components` own the HUD and input; Zustand holds persistent sky state while a mutable view module holds the camera.

**Tech Stack:** React 19, TypeScript, Vite, Zustand, lz-string, lucide-react, Fontsource, Vitest, GitHub Actions + Pages.

**Spec:** `docs/superpowers/specs/2026-10-30-starloom-design.md`

## Global Constraints

- Vite `base: '/starloom/'`.
- No personal names in code, copy, or docs.
- Every pure module has a Vitest file next to it (`*.test.ts`).
- Audio starts only from a user gesture.
- `prefers-reduced-motion`: no twinkle, no inertia, instant fly-to.

## Review Focus

- A drag that ends where it started must not place a star (tap threshold 6 px / 350 ms) — `gesture.test.ts`.
- A malformed or truncated `#sky=` hash must load the user's own sky, not crash — `share.test.ts`.
- Undo on an empty constellation removes it; undo never touches a sample/preset-free state it can't restore — `constellations.test.ts`.
- Zoom limits clamp at both ends while keeping the cursor point fixed — `camera.test.ts`.
- Day-cycle colours are continuous across the loop boundary — `daycycle.test.ts`.
